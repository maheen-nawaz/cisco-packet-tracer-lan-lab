# Multi-Tier LAN Topology & Packet Analysis in Cisco Packet Tracer

## 📌 Project Overview
Built and tested a complete local area network (LAN) connecting 9 end-user PCs and 2 servers across 4 switches using Cisco Packet Tracer. Verified full connectivity and inspected OSI layer packet movement in real time.

## 🛠️ Network Specifications
- **Servers:** Mail Server (`192.168.1.1`) & Web Server (`192.168.1.2`)
- **End Devices:** 9 PCs (`192.168.1.3` to `192.168.1.11`)
- **Subnet Mask:** `255.255.255.0`
- **Cabling:** Straight-Through (Host-to-Switch) & Crossover (Switch-to-Switch)

## 🧪 Testing & Results
1. Executed `ping 192.168.1.1` from PC Command Prompt with 0% packet loss.
2. Verified PDU packet flow across switches in Simulation Mode.
3. Analyzed Ethernet II (Layer 2) and IP/ICMP (Layer 3) headers.
